# Decisões arquiteturais

Criar ADR somente para uma decisão relevante. O curso contém candidatos, não arquivos já aprovados.
Formato: título/ID, status, contexto, alternativas, decisão, consequências e critério de revisão.
Referenciar requisito/spec e evidência quando disponíveis. Mudança local da feature pode ficar
no design.md da mudança; decisão duradoura e transversal fica neste diretório.
